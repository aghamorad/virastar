# سرور ویرایش ویراستار (Worker)

این پوشه یک «نمایندهٔ» رایگان است که ویرایش آنلاینِ ویراستار را امکان‌پذیر می‌کند:
وب‌سایت ویراستار (که روی GitHub Pages است و هیچ سروری ندارد) درخواست ویرایش را به این
Worker می‌فرستد، اینجا به گوگل‌جمینی منتقل می‌شود و جواب برمی‌گردد. کلید API گوگل فقط
اینجا نگهداری می‌شود؛ کاربران هیچ‌وقت آن را نمی‌بینند و هیچ تنظیمی لازم ندارند.

هزینه: Cloudflare و Gemini هر دو سطح رایگان دارند (برای یک اپ شخصی کاملاً کافی است).

## راه‌اندازی یک‌باره (حدود ۱۰ دقیقه)

**۱) کلید رایگان گوگل بساز**
- به `aistudio.google.com/apikey` برو و با گوگلِ خودت وارد شو.
- روی «Create API key» بزن و کلید را کپی کن.

**۲) وارد Cloudflare شو** (فقط بار اول)
```bash
cd worker
npm install
npx wrangler login
```
یک صفحهٔ مرورگر باز می‌شود؛ با حساب گوگل/ایمیلِ خودت وارد شو.

**۳) کلید گوگل را به Cloudflare بسپار**
```bash
npx wrangler secret put GEMINI_API_KEY
```
وقتی خواست، کلید مرحلهٔ ۱ را بچسبان و اینتر بزن.

**۴) منتشر کن**
```bash
npx wrangler deploy
```
در انتها یک آدرس می‌دهد، مثل `https://virastar-edit.yourname.workers.dev`.
آن آدرس را برای من بفرست تا به‌عنوان پیش‌فرضِ برنامه بگذارمش (ویرایش آنلاین برای همه کار کند).

## تست سریع (اختیاری، قبل از اینکه من آدرس را در برنامه بگذارم)
بعد از مرحلهٔ ۴ در مرورگر خودت ویراستار را باز کن و در Developer Tools این را اجرا کن:
```js
localStorage.setItem('virastar-server', 'https://virastar-edit.yourname.workers.dev')
```
بعد «ویرایش کن» را بزن؛ اگر آنلاین کار کرد، یعنی همه‌چیز درست است.

## نکتهٔ امنیتی
کلید گوگل با یک «origin» (محدود به دامنه‌های ویراستار) محافظت شده؛ اگر خواستی محدودتر کنی،
می‌توانی فهرست `DEFAULT_ALLOWED_ORIGINS` در `src/index.ts` را با یک متغیر محیطی
`ALLOWED_ORIGINS` جایگزین کنی.
