# سرور ویرایش ویراستار (Worker)

این پوشه یک «نمایندهٔ» رایگان است که ویرایش آنلاینِ ویراستار را امکان‌پذیر می‌کند:
وب‌سایت ویراستار (که روی GitHub Pages است و هیچ سروری ندارد) درخواست ویرایش را به این
Worker می‌فرستد، اینجا به هوش مصنوعی منتقل می‌شود و جواب برمی‌گردد. کلیدِ هوش مصنوعی فقط
اینجا نگهداری می‌شود؛ کاربران هیچ‌وقت آن را نمی‌بینند و هیچ تنظیمی لازم ندارند.

هزینه: Cloudflare و HuggingFace هر دو سطح رایگان دارند (برای یک اپ شخصی کاملاً کافی است).

## مدل پشت سرور

- **پیش‌فرض (بدون گوگل): HuggingFace** — مدل `Qwen/Qwen2.5-72B-Instruct` که در فارسی قوی
  است، با کلیدی که همین حالا روی سیستم هست (`~/.cache/huggingface/token`). هیچ حساب گوگل و
  هیچ کلید جدیدی لازم نیست.
- **اختیاری (بهتر): گوگل‌جمینی** — اگر بعداً کلید Gemini پیدا/ساخته شد، کافی است
  `GEMINI_API_KEY` را بگذاریم و خودکار جایگزین می‌شود (کدش در `src/index.ts` هست).

## راه‌اندازی (فقط یک ورود لازم است)

**۱) وارد Cloudflare شو** (فقط بار اول؛ این شرکتِ خودِ گوگل نیست)
```bash
cd worker
npm install
npx wrangler login
```
یک صفحهٔ مرورگر باز می‌شود. با **ایمیل و رمز، یا ورود با اپل/گیت‌هاب** وارد شو (نگو «ادامه با گوگل» چون گوگل شما را بلاک کرده).

**۲) کلید HuggingFace را به Cloudflare بده** — کلید از روی همین سیستم خوانده می‌شود:
```bash
npx wrangler secret put HF_TOKEN
# مقدار را از این فایل بردار: ~/.cache/huggingface/token
```

**۳) منتشر کن**
```bash
npx wrangler deploy
```
در انتها یک آدرس می‌دهد، مثل `https://virastar-edit.yourname.workers.dev`.
آن آدرس را برای من بفرست تا به‌عنوان پیش‌فرضِ برنامه بگذارمش (ویرایش آنلاین برای همه کار کند).

## تست سریع (اختیاری، قبل از اینکه من آدرس را در برنامه بگذارم)
بعد از مرحلهٔ ۳ در مرورگر خودت ویراستار را باز کن و در Developer Tools این را اجرا کن:
```js
localStorage.setItem('virastar-server', 'https://virastar-edit.yourname.workers.dev')
```
بعد «ویرایش کن» را بزن؛ اگر آنلاین کار کرد، یعنی همه‌چیز درست است.

## نکته‌های امنیتی
- کلید فقط روی سرور Cloudflare نگهداری می‌شود و در هیچ کدِ مرورگر نمی‌آید.
- Worker فقط از دامنه‌های فهرست‌شده در `DEFAULT_ALLOWED_ORIGINS` درخواست می‌پذیرد؛ اگر خواستی
  محدودتر کنی، آن را با متغیر محیطی `ALLOWED_ORIGINS` جایگزین کن.
