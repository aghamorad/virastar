# سرور ویرایش ویراستار (Worker)

این پوشه یک «نمایندهٔ» رایگان است که ویرایش آنلاینِ ویراستار را امکان‌پذیر می‌کند:
وب‌سایت ویراستار (که روی GitHub Pages است و هیچ سروری ندارد) درخواست ویرایش را به این
Worker می‌فرستد، اینجا به هوش مصنوعی منتقل می‌شود و جواب برمی‌گردد. کلیدِ هوش مصنوعی فقط
اینجا نگهداری می‌شود؛ کاربران هیچ‌وقت آن را نمی‌بینند و هیچ تنظیمی لازم ندارند.

هزینه: Cloudflare (سطح رایگان — چند ده‌هزار درخواست در روز) برای یک اپ شخصی کاملاً کافی است.

## مدل پشت سرور

جوابِ Worker به‌صورت «جریان» (stream) برمی‌گردد؛ یعنی برنامه در همان لحظه که مدل دارد
می‌نویسد، متن را نشان می‌دهد و کاربر لازم نیست منتظر تمام‌شدن بماند.

ترتیبِ مدل‌ها: اول مدلی که درخواست می‌گوید (برنامهٔ ویراستار پیش‌فرضش «گوگل‌جمینی» است)،
بعد بقیهٔ مدل‌هایی که این‌جا تنظیم شده‌اند. اگر یکی از کار بیفتد (مثلاً کلیدِ جمینی سهمیه‌اش
تمام شود)، خودش سریع به مدل بعدی می‌پرد و ویرایش واقعی هوش مصنوعی ادامه پیدا می‌کند — نه اینکه
به قواعد ساده بیفتد.

- **گوگل‌جمینی** — بهترین کیفیت فارسی؛ اگر `GEMINI_API_KEY` باشد، اولین انتخاب است.
- **Workers AI خودِ Cloudflare** — مدل `Llama 3.3 70B`، بدون هیچ کلیدِ خارجی؛ سرویسِ خودِ
  Cloudflare است و وقتی جمینی در دسترس نباشد جایش را می‌گیرد. اگر مدل حرفِ چینی/لاتینی در متن
  فارسی بیندازد، همین‌جا خودش را اصلاح می‌کند و حروف اضافه را پاک می‌کند.
- **اختیاری‌ها:** `WORKERS_AI_MODEL` (مدل دیگری از Workers AI) یا `HF_TOKEN` (HuggingFace) —
  به‌عنوان آخرین گزینهٔ پشتیبان.

## راه‌اندازی (فقط یک ورود لازم است؛ نیازی به کلید نیست)

**۱) وارد Cloudflare شو** (فقط بار اول؛ این شرکتِ خودِ گوگل نیست)
```bash
cd worker
npm install
npx wrangler login
```
یک صفحهٔ مرورگر باز می‌شود. با **ایمیل و رمز، یا ورود با اپل/گیت‌هاب** وارد شو (نگو «ادامه با گوگل» چون گوگل شما را بلاک کرده).

**۲) منتشر کن** — اتصال به هوش مصنوعی از قبل در `wrangler.toml` تنظیم است (`[ai] binding = "AI"`):
```bash
npx wrangler deploy
```
در انتها یک آدرس می‌دهد مثل `https://virastar-edit.kharkhan.workers.dev`. آدرسِ فعلیِ برنامه از قبل
در `domain/engine.ts` به‌عنوان پیش‌فرض گذاشته شده؛ اگر آدرس عوض شد، همان یک خط را به‌روز کن و دوباره منتشر کن.

**۳) (اختیاری) مدل دیگری بگذار** — برای عوض‌کردن مدلِ Workers AI:
```bash
npx wrangler secret put WORKERS_AI_MODEL
# مثلاً: @cf/meta/llama-3.3-70b-instruct-fp8-fast
```

## تست سریع
در مرورگر «ویرایش کن» را بزن؛ اگر برچسب نتیجه «آنلاین» شد و متنِ روانِ فارسی برگشت، همه‌چیز درست است.

## نکته‌های امنیتی
- کلید فقط روی سرور Cloudflare نگهداری می‌شود و در هیچ کدِ مرورگر نمی‌آید.
- Worker فقط از دامنه‌های فهرست‌شده در `DEFAULT_ALLOWED_ORIGINS` درخواست می‌پذیرد؛ اگر خواستی
  محدودتر کنی، آن را با متغیر محیطی `ALLOWED_ORIGINS` جایگزین کن.
